## Operating entry points

An existing verified account receives an explicit grant using the offline migration role, with `platform:grant USER_ID --permission=platform.owner --operator="ACCOUNTABLE OPERATOR" --reason="REASON"`. No account or credential is seeded. The operator signs in normally, opens `/admin/security`, enrolls an authenticator and verifies password plus a fresh code. `/admin` exposes metadata and subscription assignment only. `directory.read` and `plans.assign` can be granted separately; use both for a directory-based assignment operator. Offline `--recover` resets the authenticator and invalidates sessions/grant proofs; `--revoke` preserves history and refuses removal of the last usable owner. These instructions describe implemented code, not authorization to provision a real operator.
